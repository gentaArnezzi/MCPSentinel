# Security Policy

## Supported versions

The latest release in the `0.2.x` line receives security fixes. Upgrade to the newest published version before reporting an issue.

## Reporting a vulnerability

Do not open a public GitHub issue for a suspected vulnerability. Use GitHub's private security advisory flow for this repository, or contact the repository owner through the address listed on the GitHub profile. Include a minimal reproduction, affected version, impact, and any suggested mitigation.

We will acknowledge reports promptly, validate the issue, and coordinate a fix before public disclosure when practical.
